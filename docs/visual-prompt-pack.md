# Miner Space — Pack de prompts visuels

## 1. Objectif

Ce document fournit des prompts de base pour produire des références visuelles cohérentes.

## 2. Règle générale commune

Tous les prompts doivent rappeler :

- style science-fiction industrielle stylisée ;
- rendu low-poly premium ;
- lisibilité mobile ;
- silhouettes claires ;
- matériaux métal sombre + néons + énergie ;
- ambiance immersive ;
- cohérence avec Miner Space.

## 3. Prompt global DA

> Créer une direction artistique pour un jeu mobile de gestion spatiale appelé Miner Space. Style science-fiction industrielle élégante, low-poly premium, vue 2.5D, lisibilité mobile élevée, matériaux métal sombre, verre, cristaux énergétiques, néons cyan et accents orange, ambiance addictive, propre et spectaculaire.
