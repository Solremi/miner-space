# Miner Space — Pack de production visuelle et assets

## 1. Objectif

Ce document définit les familles d’assets à produire, leurs priorités et les règles de cohérence visuelle.

## 2. Ce que GPT peut fournir immédiatement

- bible artistique ;
- concepts textuels précis ;
- fiches de silhouettes ;
- spécification UI ;
- fiches de production par asset ;
- liste hiérarchisée d’assets ;
- prompts visuels ;
- structure de nommage ;
- intentions d’animation.

## 3. Ce qui nécessitera une phase ultérieure

- modèles 3D finaux ;
- UV ;
- textures optimisées ;
- rigging ;
- animation 3D finale ;
- exports `.glb` / `.gltf` prêts au jeu.

## 6. Fiches par asset

Chaque asset important devra recevoir une fiche contenant :

- identifiant ;
- catégorie ;
- rôle gameplay ;
- silhouette ;
- taille relative ;
- matériaux ;
- couleurs dominantes ;
- niveau de détail ;
- animation attendue ;
- évolution éventuelle ;
- contraintes mobile.

## 7. Exemple de fiche — robot EX de base

- **ID** : `robot_ex_mk1`
- **Rôle** : extraction de base
- **Silhouette** : compacte, stable, bras de forage frontal
- **Matériaux** : métal graphite, pièces orange, noyau cyan
- **Personnalité visuelle** : robuste, travailleur, fiable
- **Animation** : rotation du foret, recul léger, petites étincelles
- **Évolution** : pièces renforcées, tête plus avancée, halo énergétique accru
- **Contrainte** : lisible en petite taille sur vue paysage
