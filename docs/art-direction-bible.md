# Miner Space — Bible artistique

## 1. Objectif

Cette bible artistique définit l’identité visuelle de **Miner Space** afin de garantir une cohérence forte entre :

- les planètes ;
- les robots ;
- les bâtiments ;
- les ressources ;
- les effets visuels ;
- l’interface ;
- les visuels marketing.

Le jeu doit transmettre simultanément :

- **exploration spatiale** ;
- **industrie élégante** ;
- **progression technologique** ;
- **satisfaction visuelle** ;
- **lisibilité mobile**.

## 2. Direction générale

### 2.1 Positionnement visuel

Miner Space adopte un style :

- **science-fiction industrielle stylisée** ;
- **3D low-poly propre** ;
- **semi-réaliste mais accessible** ;
- **mobile-first** ;
- **spectaculaire sans surcharge**.

Le rendu doit être à mi-chemin entre :

- un jeu de gestion mobile lisible ;
- une petite scène 3D vivante ;
- une interface holographique futuriste.

### 2.2 Impression recherchée

Le joueur doit ressentir :

1. « Je construis quelque chose de plus en plus puissant. »
2. « Mon complexe spatial devient plus beau et plus avancé. »
3. « Chaque planète a une vraie personnalité. »
4. « Ce jeu est propre, premium et satisfaisant. »

## 3. Principes de style

### 3.1 Formes

Privilégier :

- silhouettes lisibles ;
- volumes simples ;
- angles nets avec arrondis localisés ;
- pièces modulaires ;
- éléments mécaniques crédibles mais simplifiés.

Éviter :

- micro-détails inutiles ;
- bruit visuel ;
- réalisme sale excessif ;
- formes organiques floues hors contenus narratifs spécifiques ;
- contours trop fins pour mobile.

### 3.2 Matériaux dominants

- métal graphite ;
- acier satiné ;
- alliage titane ;
- verre sombre ;
- surfaces lumineuses néon ;
- cristaux énergétiques ;
- panneaux composites.

### 3.3 Finition globale

- matériaux propres mais pas stériles ;
- usure légère progressive sur les robots vétérans ;
- lumières localisées et contrôlées ;
- contraste fort entre matière industrielle sombre et énergie lumineuse.

## 4. Palette globale

### 4.1 Couleurs de base du jeu

Couleurs transversales :

- **Graphite profond** — structures et bases
- **Acier bleuté** — mécanismes secondaires
- **Blanc froid** — textes importants / surfaces premium
- **Cyan holographique** — interface, scanners, sélection
- **Orange énergie** — activité industrielle, extraction, avertissements doux
- **Violet quantique** — haute technologie, antimatière, contenus rares
- **Vert système** — états stables, validation, productivité

### 4.2 Règles de palette

- une planète = une palette dominante + une palette d’accent ;
- l’interface conserve une cohérence commune entre les planètes ;
- les raretés suivent une hiérarchie constante ;
- les couleurs ne sont jamais la seule source d’information ; formes, halos et icônes complètent toujours la lecture.

## 5. Hiérarchie des raretés

| Niveau | Couleur dominante | Traitement visuel |
|---|---|---|
| Commun | gris / bleu neutre | simple, stable, sobre |
| Peu commun | cyan / vert doux | léger halo, accent lumineux |
| Rare | orange / bleu intense | halo net, éclat visible |
| Épique | violet / magenta | pulsation, géométrie premium |
| Légendaire | or froid / blanc intense / violet | présence scénique, particules distinctes |
| Exceptionnel | palette dédiée selon la ressource | carte de découverte, arrêt visuel bref |

## 6. Style des planètes

## 6.1 Ferrum Delta

### Identité

- désert minéral rouge sombre ;
- atmosphère poussiéreuse ;
- industrie naissante ;
- monde d’introduction mais déjà impressionnant.

### Palette

- rouge ferrique ;
- brun rouille ;
- gris anthracite ;
- orange chaud ;
- cyan pour la technologie.

### Décor

- roches anguleuses ;
- plaques minérales ;
- canyons modestes ;
- poussière légère ;
- ruines discrètes.

### Ambiance

Ferrum Delta doit évoquer le début de l’aventure, la colonisation et la montée progressive de la puissance industrielle.

## 6.2 Cryos IX

### Identité

- monde glacé ;
- froid lumineux ;
- technologie thermique ;
- sophistication cristalline.

### Palette

- bleu glacier ;
- turquoise ;
- blanc froid ;
- violet bleuté ;
- orange thermique en contraste.

### Décor

- falaises de glace ;
- cristaux lumineux ;
- fissures gelées ;
- vapeur ;
- structures chauffées.

### Ambiance

Cryos IX doit donner le sentiment d’un monde plus hostile, plus technologique et plus précieux que Ferrum Delta.

## 6.3 Vulkaris (prévision)

### Identité

- volcanique ;
- surchauffe ;
- métal fondu ;
- puissance brute.

### Palette

- noir lave ;
- rouge incandescent ;
- orange magma ;
- jaune thermique ;
- turquoise minimal pour les systèmes de contrôle.

## 7. Style des robots

## 7.1 Principes communs

Tous les robots doivent :

- être immédiatement identifiables par leur silhouette ;
- être lisibles à faible taille ;
- transmettre leur fonction ;
- posséder un noyau lumineux ou un élément d’identité fort ;
- pouvoir évoluer visuellement avec le niveau.

### 7.2 Langage de forme par type

#### EX — Robot extracteur

- silhouette compacte et puissante ;
- centre de gravité bas ;
- bras de forage ;
- tête mécanique identifiable ;
- accent de couleur orange / minier.

#### RF — Robot raffineur

- silhouette plus verticale ;
- chambres de transformation ;
- conduits énergétiques ;
- éléments lumineux internes ;
- accent cyan / vert / violet selon matière.

#### AS — Robot assembleur

- silhouette articulée ;
- bras multiples ;
- zones d’assemblage ;
- projection holographique ;
- accent bleu / cyan / blanc.

#### LG — Robot logistique

- silhouette rapide ;
- modules de transport ;
- lignes fluides ;
- capacité à évoquer le déplacement ;
- accent vert / cyan.

## 7.3 Évolution visuelle des robots

À chaque palier important :

- ajout d’une pièce visible ;
- augmentation de la qualité lumineuse ;
- amélioration du matériau ;
- signes de spécialisation ;
- animation plus fluide ou plus confiante.

Les robots vétérans reçoivent :

- marques d’usure élégantes ;
- insignes ;
- trait distinctif ;
- variation chromatique légère ;
- noyau plus expressif.

## 8. Style des bâtiments

## 8.1 Règles générales

- base modulaire ;
- architecture industrielle avancée ;
- pièces visibles et compréhensibles ;
- identité fonctionnelle forte ;
- taille lisible en vue paysage.

## 8.2 Bâtiments clés

### Centre de commandement

- cœur visuel de la base ;
- silhouette forte ;
- hologrammes visibles ;
- noyau lumineux ;
- impression de contrôle.

### Raffinerie

- cuves, chambres, conduits, lumière interne ;
- transformation visible ;
- sortie des matériaux raffinés mise en scène.

### Atelier robotique

- bras mécaniques ;
- plates-formes ;
- animation d’assemblage ;
- silhouette semi-circulaire ou en baie technique.

### Scanner

- antennes ;
- radar holographique ;
- faisceaux ;
- lecture verticale forte.

### Chantier du vaisseau

- structure monumentale ;
- échafaudage spatial ;
- grande lisibilité ;
- véritable objectif visuel de fin de planète.

## 9. Style des ressources

## 9.1 Ressources brutes

Les minerais doivent être :

- lisibles au premier regard ;
- visuellement distincts ;
- regroupés par famille ;
- compatibles avec une représentation de gisement et d’icône.

### Exemples

- Ferrite : roche sombre à veines rouges / métalliques ;
- Silicate : roche claire cristalline ;
- Carbone dense : blocs noirs mats ;
- Cuivre stellaire : roche brun-orangée conductrice ;
- Cobalt : bleu métallique ;
- Titane : gris lumineux propre ;
- Iridium : métal rare à reflets froids ;
- Cristal de xénon : cristal énergétique cyan / violet ;
- Résidu d’antimatière : matériau instable violet-blanc.

## 9.2 Ressources raffinées

Elles doivent paraître premium, propres et désirables.

- Plaque de ferrite : plaque métallique nette ;
- Bobine conductrice : composant soigné, presque électronique ;
- Cellule cobalt : capsule énergétique ;
- Diamant xénon : cristal facetté lumineux ;
- Cellule d’antimatière : objet final à forte aura visuelle.

## 10. Effets visuels

## 10.1 Règles

Les VFX doivent renforcer :

- la compréhension ;
- la satisfaction ;
- la rareté ;
- la montée en puissance.

Ils ne doivent pas masquer le gameplay.

## 10.2 Effets principaux

- faisceau de forage ;
- impacts de minage ;
- particules de poussière ;
- matière circulant dans les conduits ;
- cristallisation ;
- étincelles d’assemblage ;
- halo de découverte ;
- impulsion de scanner ;
- onde d’ouverture de secteur ;
- météorites et traînées ;
- séquence de décollage.

## 10.3 Satisfaction visuelle

Chaque action importante doit avoir :

- activation visible ;
- petite montée d’énergie ;
- retour de confirmation ;
- transformation légère ou animation du système concerné.

## 11. Interface et HUD

## 11.1 Style UI

- interface holographique moderne ;
- panneaux sombres semi-transparents ;
- contours lumineux fins ;
- typographie claire ;
- pictogrammes simples ;
- hiérarchie visuelle nette.

## 11.2 Règles UI

- pas de surcharge ;
- peu de texte visible simultanément ;
- informations clés toujours accessibles ;
- boutons volumineux ;
- états désactivés compréhensibles ;
- actions importantes confirmées visuellement.

## 11.3 Typographie

Rechercher une typographie :

- sans serif ;
- futuriste discrète ;
- très lisible ;
- utilisable en petits corps.

Séparer :

- titres ;
- labels ;
- valeurs ;
- compteurs.

## 12. Marketing visuel

Les visuels marketing doivent mettre en avant :

- la planète ;
- les robots ;
- les effets lumineux ;
- la montée technologique ;
- le côté satisfaisant de la transformation des ressources.

Le contraste entre :

- paysage spatial / minéral ;
- technologie brillante ;
- chaîne industrielle ;

constitue la signature visuelle du jeu.

## 13. Contraintes de production

- privilégier des modèles réutilisables ;
- construire une bibliothèque modulaire ;
- garder des silhouettes simples ;
- prévoir qualité faible / moyenne / élevée ;
- limiter les matériaux différents par objet ;
- éviter les textures immenses ;
- penser lisibilité sur petit écran avant toute richesse de détail.

## 14. Résumé artistique

Miner Space doit être perçu comme :

> un jeu spatial de gestion et d’automatisation au rendu low-poly premium, où l’industrie, l’exploration et la technologie se rencontrent dans une ambiance spectaculaire, propre et addictive.
